# Devlog 1 — Layout ([1.1](https://lapse.hackclub.com/timelapse/5RdF5y88RQ2I), [1.2](https://lapse.hackclub.com/timelapse/ZesBQOfE4MBa)) - Oliver
I started by making a basic layout for the keyboard, also adding labels for keys, split into sections which would become sperate modules in a later stage.

# Devlog 2 — Case top plate ([2.1](https://lapse.hackclub.com/timelapse/eL3xCuvjLT37), [2.2](https://lapse.hackclub.com/timelapse/BLe_rd5PpnxV), [2.3](https://lapse.hackclub.com/timelapse/aRtAsJun4Mp-), [2.4](https://lapse.hackclub.com/timelapse/QBHegsUPQNaj)) - Oliver
Made the top plate for they keyboard using the standard spacing of 19.05mm between 1u keys, with 14mm^2 holes for the switches, also added wells for the keycaps so they have full ROM.

# Devlog 3 — Pogo pins design ([3.1](https://lapse.hackclub.com/timelapse/cRwvfFemOQyj)) - Oliver
Designed the symbol and footprint for the connectors between modules, these will be [pogo pins](https://www.amazon.co.uk/1Pair-Magnetic-Pogo-Pin-Connector-Black/dp/B0D1KRT3JL) and be added using small wires from each pin of the footprint to the pogo pin.

# Devlog 4 — Keycap design ([4.1](https://lapse.hackclub.com/timelapse/chCaECsFfF9g0), [4.2](https://lapse.hackclub.com/timelapse/_NjUM8mT0LGT )) - Oliver
Made the keycaps and positioned in the correct arrangement, there are 97 * 1U, 8 * 1.25U, 2 * 1.5U, 2 * 1.75U, 4 * 2U, 2 * 3U

# Devlog 5 — Main section routing ([5.1](https://lapse.hackclub.com/timelapse/dGQNtbVD7vZd), [5.2](https://lapse.hackclub.com/timelapse/8pVt1Rht81yD)) - Oliver
Routed the PCB for the main alphanumeric keyboard, this includes the MCU as well as the 63 key matrix.

# Devlog 6 — BMS, FN row and Macros ([6.1](https://lapse.hackclub.com/timelapse/crsrca5HazF8y), [6.2](https://lapse.hackclub.com/timelapse/_uE7_6aOiJ-wT)) - Oliver
Routed the BMS for the LiPo, then routed the matrix for the FN row as well as the Macro buttons

# Devlog 7— Finished off the PCB ([6.1](https://lapse.hackclub.com/timelapse/CuVCEyVKinYO)) - Oliver
Routed the Numpad and the Navigation section. PCB Done!!
